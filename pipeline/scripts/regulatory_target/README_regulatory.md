<p style="font-family: Arial, Helvetica, sans-serif; font-size: 1.05em; line-height: 1.6; color: #4b5563;"><code>&lt;PROJECT_ROOT&gt;/pipeline/regulatory_work/</code> — final integration products linking CUT&amp;RUN promoter binding to bulk RNA-seq differential expression.</p>

It is generated by `scripts/regulatory_target/07_define_regulatory_targets.py` after Step 05 has established factor-specific promoter-bound gene sets.

> `<PROJECT_ROOT>` is a portable placeholder for the directory containing the repository clone. The workspace is not a standalone analysis: it requires RNA-seq DEG tables, Step 05 promoter-binding evidence, and Step 04 display-scaled mean BigWigs.

## Analytical objective

For each factor, the workflow identifies genes that are both promoter-bound and differentially expressed in the associated RNA-seq contrast. These direct regulatory-target sets are classified by expression direction and partitioned into MCM3, NONO, and PSPC1 overlap groups. Signal metaprofiles use the corresponding CUT&RUN mean tracks to describe occupancy across target groups.

## Workspace structure

| Folder | Contents | Produced by |
| --- | --- | --- |
| `data/` | Regulatory-target gene lists, raw promoter/DEG overlap tables, direction summaries, Venn memberships/counts, group definitions, BED regions, and metaprofile source tables. | Step 07 R renderers. |
| `visuals/` | Regulatory-target Venn diagrams, factor-specific direction panels, group pie charts, and factor/group metaprofiles. | Step 07 R renderers. |

| File | What it records |

## What Step 07 accomplishes

1. Reads final promoter-bound gene sets from `cutrun_work/05_promoters/`.
2. Reads the factor-matched bulk RNA-seq DEG tables from `deg_work/data/`.
3. Intersects these gene sets to define direct regulatory targets and classifies target directionality.
4. Writes auditable gene-level memberships, overlap counts, and summary tables to `data/`.
5. Uses `cutrun_work/03_bigwig/IGV_representation/` mean tracks with deepTools to render occupancy metaprofiles.
6. Writes final Venn, directional, composition, and metaprofile figures to `visuals/`.

## Interpretation and reporting

Use `data/promoter_vs_DEG_direction_summary.tsv` to report factor-level direct-target totals, and `data/Venn_target_counts.tsv` to report overlap counts. Use the tables—not only the figures—for quantitative reporting and supplementary data deposition.

The observed output can support statements about association between promoter occupancy and expression response under the documented perturbation, but it does not independently establish direct biochemical mechanism. Report the DEG contrast, reference annotation, peak threshold, promoter-overlap rule, and replicate-level factor/IgG criterion alongside any biological interpretation.

## Reproducibility checklist

- Preserve Step 07 logs and the exact revision of `07_define_regulatory_targets.py`.
- Archive `data/` tables together with the figures in `visuals/`.
- Retain the upstream CUT&RUN BigWigs and promoter-support tables required to regenerate target metaprofiles.
- Cite the workflow and its principal software as described in the main README.
